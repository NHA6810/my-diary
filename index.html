第一次使用？看这里
  1. 站点代码在公开仓库 NHA6810/my-diary 的 main 分支，由 GitHub Actions 自动发布到本页地址。
  2. 日记归档在私有仓库 NHA6810/my-diary-data（已建好，下面默认已填），Markdown 与图片都不会出现在公开站点。
  3. 打开 GitHub → Settings → Developer settings → Fine-grained tokens，生成令牌：Repository access 只选 my-diary-data，Permissions 里把 Contents 设为 Read and write。
  4. 把令牌填到上面，点「测试连接」，成功后保存设置。
  5. 之后每篇日记会以 diaries/年/月/2026-11-12.md 归档，图片放在 diaries/assets/日期/。

本站已运行在 HTTPS 上，语音识别、录音与 GitHub 接口均可直接使用。同一台手机上首次配置一次即可，之后自动归档。
